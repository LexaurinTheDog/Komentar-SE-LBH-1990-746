# Kommentar till lagen (1990:746) om betalningsföreläggande och handräckning

Kommentar till svensk författning: **Lag (1990:746) om betalningsföreläggande och handräckning** (SFS 1990:746). Kommentaren omfattar **71 enheter** (70 paragrafer, 1–66 §§ inklusive 6 a, 60 a, 61 a och 61 b §§ samt de upphävda 6 a, 7 och 8 §§, och övergångsbestämmelserna) fördelade på 3 kommentarskapitel; vid varje enhet återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2020:924** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=1990:746](https://rkrattsbaser.gov.se/sfst?bet=1990%3A746) · [data.riksdagen.se/dokument/sfs-1990-746](https://data.riksdagen.se/dokument/sfs-1990-746.json)
